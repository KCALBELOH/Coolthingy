#ASFSMOD Introduce Johns Solar System (Short for JSS, other name : Plane Change), a expanse galaxy with stars, and exoplanets, unique destinations, and many more!
How to insert: 
Go inside zip (if you downloaded it as a zip), 
Go to the main folder, press VeryCoolGalaxy.zip, 
Press the folder named JSS V.5.0.0 (or has JSS in its name whatever), right click it and copy it, Go to steam, press Browse files on Gear button, press Spaceflight Simulator_data, press Custom Solar Systems, Put the copied Brias galaxy folder here, done!
