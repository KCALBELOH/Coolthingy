An SFS planet pack.

Introduce Johns Solar System (Short for JSS, other name : Plane Change), a expanse galaxy with stars, and exoplanets, unique destinations, and many more! Scales are 10 times smaller than real life, But, eccentricity, etc, is accurate, or halfly accurate, There are fictional, hypothetical planets here, and even ones you never seen before.

How to insert: 

Press code, press download zip.

Go inside zip (if you downloaded it as a zip), 

Go to the main folder, press JSS.zip (or something similar), 

Press the folder named Plane Change / JSS (there will be both of them, Place Plane Change 2A1 files inside Plane Change 2), right click it and copy it, Go to steam, press Browse files on Gear button, press Spaceflight Simulator_data, press Custom Solar Systems, Put the copied folder here, done!
